# Open Matter Labs public site

Minimal public-facing site for [openmatterlabs.org](https://openmatterlabs.org/).

The private `dft2` and `casmi` repositories are not included here. Only selected,
reviewed results, charts, and public notices should be published.

## Current stage

This repository is intentionally static and dependency-free for the first landing-page
release. The public noticeboard is a read-only preview with no public submission or
comment form. Do not add an unauthenticated form to GitHub Pages: static client-side
forms cannot provide secure moderation or spam resistance.

## GitHub Pages

1. Push this repository to `vornvoskhq/vornvoskhq.github.io`.
2. In GitHub, open **Settings → Pages** and select the deployment source.
3. Set the custom domain to `openmatterlabs.org`.
4. Keep HTTPS enforcement enabled after GitHub verifies the domain.
5. The `CNAME` file is already present in the site root.

The exact DNS records depend on the DNS nameservers currently active at Spaceship. Do
not remove existing records blindly; preserve any registrar verification records.

## Zoho Mail DNS checklist

Create the Zoho organization and add `openmatterlabs.org` in the Zoho Mail Admin
Console. Zoho's current regional MX hostnames and priorities must be copied from the
Admin Console rather than guessed from an old tutorial.

At Spaceship DNS, add the records Zoho gives you:

- domain-verification TXT record;
- all Zoho MX records, with Zoho's exact priorities;
- Zoho SPF TXT value (normally an `include:zohomail...` value shown by Zoho);
- DKIM TXT record for the selector generated by Zoho;
- DMARC TXT record after mail flow is verified, initially with a monitoring policy;
- any Zoho CNAME records required for webmail or service verification.

Recommended initial mailboxes/aliases:

- `hello@openmatterlabs.org` — public contact;
- `admin@openmatterlabs.org` — account administration;
- `research@openmatterlabs.org` — research/data contact;
- `dmarc@openmatterlabs.org` — aggregate DMARC reports if enabled.

Use Zoho Webmail for the private mailbox/admin portal:

- https://mail.zoho.com/
- https://www.zoho.com/mail/help/adminconsole/

Never commit Zoho credentials, recovery codes, or DNS API tokens to this repository.

## Planned board backend

The selected backend direction is Convex, connected to this static frontend after the
landing page is published. The future backend must provide:

- admin-authenticated post creation/editing/deletion;
- image upload with size/type limits;
- link validation and safe external-link rendering;
- public read-only post queries;
- comments disabled by default until moderation is ready;
- authenticated or verified comment identity;
- server-side rate limiting, duplicate detection, length limits, and moderation;
- report/hide/delete controls;
- audit records for administrative actions;
- no secrets in GitHub Pages client code.

The first secure board release should be staged separately from the landing page and
should not be considered complete until abuse cases and moderation behavior are tested.
